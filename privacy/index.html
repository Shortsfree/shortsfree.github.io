개인정보처리방침

ShortsFree Guard는 사용자의 개인정보를 중요하게 생각합니다.

시행일: 2026년 9월 25일

ShortsFree(이하 “서비스”)는 사용자의 개인정보를 중요하게 생각합니다. 본 개인정보처리방침은 브라우저 확장 프로그램 ShortsFree Guard가 어떤 정보를 처리하고, 해당 정보를 어떤 목적으로 사용하는지 설명합니다.

1. ShortsFree Guard가 처리하는 정보

ShortsFree Guard는 YouTube Shorts 사용 시간을 측정하고 사용자가 설정한 제한을 적용하기 위해 다음 정보를 처리할 수 있습니다.

  • 사용자가 YouTube Shorts 페이지를 이용 중인지 여부
  • YouTube Shorts 시청 시간
  • 사용 날짜 및 측정 시각
  • 확장 프로그램 설치를 구분하기 위해 생성되는 임의의 식별자
  • ShortsFree 데스크톱 앱과 동기화하는 데 필요한 Shorts Guard 상태 정보

ShortsFree Guard는 사용자의 이름, 이메일 주소, 비밀번호, 결제정보, 건강정보, 정확한 위치정보, 개인적인 메시지 등의 정보를 확장 프로그램을 통해 수집하지 않습니다.

2. 정보 이용 목적

처리되는 정보는 다음과 같은 ShortsFree Guard의 핵심 기능을 제공하기 위해서만 사용됩니다.

  • YouTube Shorts 시청 여부 확인
  • 일일 Shorts 시청 시간 측정
  • 사용자가 설정한 Shorts 허용 시간 적용
  • 허용 시간 도달 시 Shorts 차단
  • 추가 시청 시간 기능 제공
  • ShortsFree 집중 모드와 연동한 Shorts 차단
  • ShortsFree 데스크톱 앱과 Shorts 사용 시간 및 Guard 상태 동기화

이러한 정보는 ShortsFree Guard의 기능 제공과 관련 없는 목적으로 사용하지 않습니다.

3. 정보의 저장 및 전송

ShortsFree Guard는 Shorts 사용 시간, 사용 날짜 및 확장 프로그램의 임의 식별자 등 기능 수행에 필요한 일부 정보를 브라우저의 로컬 저장소에 저장할 수 있습니다.

또한 ShortsFree 데스크톱 앱이 실행되고 있는 경우, Shorts 사용 시간과 Guard 상태 등의 정보를 사용자의 기기에서 실행되는 로컬 서버(127.0.0.1)를 통해 ShortsFree 데스크톱 앱과 주고받을 수 있습니다.

이 통신은 사용자의 기기 내부에서 ShortsFree Guard와 ShortsFree 데스크톱 앱을 연동하기 위한 목적으로 사용됩니다.

4. 제3자 제공 및 판매

ShortsFree Guard는 확장 프로그램을 통해 처리하는 사용자 데이터를 제3자에게 판매하지 않습니다.

또한 사용자 데이터를 광고, 신용평가 또는 대출 등의 목적으로 사용하지 않습니다.

5. 웹사이트 접근 권한

ShortsFree Guard는 핵심 기능을 제공하기 위해 YouTube 웹사이트에 접근합니다.

해당 접근 권한은 YouTube Shorts 사용 여부를 확인하고, 시청 시간을 측정하며, 사용자가 설정한 제한 또는 집중 모드 상태에 따라 Shorts 차단 기능을 제공하기 위해 사용됩니다.

ShortsFree Guard는 이러한 목적과 관련 없는 웹사이트 이용 정보를 수집하기 위해 해당 권한을 사용하지 않습니다.

6. 브라우저 권한 사용

scripting YouTube Shorts 페이지에 제한 안내 화면을 표시하고 Shorts 차단 기능을 제공하기 위해 사용합니다.

7. 원격 코드

ShortsFree Guard는 원격 서버에서 JavaScript 또는 WebAssembly 등의 실행 코드를 다운로드하여 실행하지 않습니다.

확장 프로그램의 실행 코드는 배포되는 확장 프로그램 패키지에 포함되어 있습니다.

8. 데이터 보안

ShortsFree는 ShortsFree Guard가 처리하는 정보를 핵심 기능 제공에 필요한 범위로 제한하고, 불필요한 사용자 정보를 수집하지 않도록 노력합니다.

9. 개인정보처리방침 변경

ShortsFree Guard의 기능 또는 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침도 변경될 수 있습니다.

중요한 변경사항이 있는 경우 적절한 방법을 통해 변경 내용을 안내할 수 있습니다.

Privacy Policy

ShortsFree Guard respects your privacy.

Effective date: September 25, 2026

ShortsFree ("the Service") respects your privacy. This Privacy Policy explains what information the ShortsFree Guard browser extension processes and how that information is used.

1. Information Processed by ShortsFree Guard

ShortsFree Guard may process the following information to measure YouTube Shorts usage and enforce the viewing limits configured by the user.

  • Whether the user is currently using a YouTube Shorts page
  • YouTube Shorts viewing time
  • Usage date and measurement time
  • A randomly generated identifier used to distinguish extension installations
  • Shorts Guard state information required for synchronization with the ShortsFree desktop app

ShortsFree Guard does not collect the user's name, email address, password, payment information, health information, precise location, private messages, or similar personal information through the browser extension.

2. Purpose of Information Processing

The information described above is used only to provide the core functionality of ShortsFree Guard, including:

  • Detecting YouTube Shorts usage
  • Measuring daily Shorts viewing time
  • Enforcing the Shorts viewing limit configured by the user
  • Blocking Shorts when the configured limit is reached
  • Providing the additional viewing time feature
  • Blocking Shorts in connection with ShortsFree Focus Mode
  • Synchronizing Shorts usage time and Guard state with the ShortsFree desktop app

This information is not used for purposes unrelated to providing ShortsFree Guard functionality.

3. Information Storage and Transmission

ShortsFree Guard may store certain information required for its functionality, such as Shorts usage time, usage date, and a randomly generated extension identifier, in the browser's local storage.

When the ShortsFree desktop app is running, ShortsFree Guard may exchange information such as Shorts usage time and Guard state with the ShortsFree desktop app through a local server running on the user's device at 127.0.0.1.

This communication is used to connect ShortsFree Guard with the ShortsFree desktop app locally on the user's device.

4. Third-Party Sharing and Sale

ShortsFree Guard does not sell user data processed through the browser extension to third parties.

User data is also not used for advertising, credit assessment, lending, or similar purposes.

5. Website Access

ShortsFree Guard accesses the YouTube website in order to provide its core functionality.

This access is used to detect YouTube Shorts usage, measure viewing time, and block Shorts according to the user's configured viewing limit or Focus Mode status.

ShortsFree Guard does not use this permission to collect browsing information unrelated to these purposes.

6. Browser Permissions

scripting Used to display viewing-limit notices on YouTube Shorts pages and provide Shorts blocking functionality.
storage Used to store state required for the extension's functionality in the user's browser, including Shorts usage time, date, and the randomly generated extension identifier.
YouTube host permission Used to detect YouTube Shorts pages and provide Shorts Guard functionality.
localhost host permission Used to synchronize Shorts usage time and Guard state with the ShortsFree desktop app running on the user's device.

7. Remote Code

ShortsFree Guard does not download and execute JavaScript, WebAssembly, or other executable code from remote servers.

All executable extension code is included in the distributed extension package.

8. Data Security

ShortsFree limits the information processed by ShortsFree Guard to what is necessary to provide its core functionality and seeks to avoid collecting unnecessary user information.

9. Changes to This Privacy Policy

This Privacy Policy may be updated if ShortsFree Guard's functionality or data processing practices change.

If significant changes are made, users may be informed through an appropriate method.
